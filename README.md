# 🩹 בוט עזרה ראשונה – RAG

בוט שעונה על שאלות **רק** מתוך מסמכי ה-Word בנושא עזרה ראשונה, בעזרת LlamaIndex, ChromaDB ו-Google Gemini.

## מבנה הפרויקט

| קובץ | תפקיד |
|------|-------|
| `config.py` | כל ההגדרות במקום אחד + `setup_models()` |
| `build_index.py` | בונה את האינדקס מקבצי ה-docx ושומר ב-Chroma |
| `rag.py` | טעינת האינדקס, הרחבת שאלה, חיפוש ויצירת תשובה |
| `app.py` | ממשק הצ'אט ב-Streamlit |
| `data/` | כאן שמים את קבצי ה-Word (כבר כולל את המסמך `עזרה ראשונה.docx`) |
| `chroma_db/` | נוצרת אוטומטית – מסד הנתונים הווקטורי |

## התקנה ב-Windows

1. **התקנת Python** (גרסה 3.11 או 3.12) מ-[python.org](https://www.python.org/downloads/).
   בהתקנה חשוב לסמן ✅ **Add python.exe to PATH**.

2. **פתיחת PowerShell בתיקיית הפרויקט** ויצירת סביבה וירטואלית:
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```
   > אם מופיעה שגיאה על הרשאות הרצת סקריפטים, הריצי פעם אחת:
   > `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

3. **התקנת החבילות:**
   ```powershell
   pip install -r requirements.txt
   ```

4. **מפתח API:** קבלי מפתח חינמי ב-[Google AI Studio](https://aistudio.google.com/apikey).
   העתיקי את `.env.example` לקובץ חדש בשם `.env` והדביקי בו את המפתח:
   ```
   GOOGLE_API_KEY=המפתח-שלך
   ```

## הרצה

1. שימי את קבצי ה-`.docx` בתיקייה `data`.
2. בניית האינדקס (פעם אחת, ושוב בכל שינוי במסמכים):
   ```powershell
   python build_index.py
   ```
3. הפעלת הצ'אט:
   ```powershell
   streamlit run app.py
   ```
   הדפדפן ייפתח אוטומטית בכתובת http://localhost:8501

> בדיקה מהירה בטרמינל בלי ממשק: `python rag.py`

## הסבר על 9 ההחלטות הטכניות

1. **ChromaDB עם PersistentClient** – מסד נתונים וקטורי פשוט שרץ מקומית ושומר לדיסק (`chroma_db`), כך שלא צריך לחשב את הווקטורים מחדש בכל הפעלה.
2. **LlamaIndex** – ספרייה שמחברת את כל החלקים (טעינת מסמכים, חלוקה, embedding, חיפוש, LLM) עם מעט קוד.
3. **SentenceSplitter, chunk_size=512 טוקנים** – מחלק את הטקסט לחתיכות בגודל בינוני, ומשתדל לא לחתוך באמצע משפט. חתיכה קטנה מדי מאבדת הקשר; גדולה מדי מכניסה "רעש".
4. **chunk_overlap=50** – חפיפה קטנה בין חתיכות סמוכות, כדי שמידע שנופל על הגבול בין שתי חתיכות לא ילך לאיבוד.
5. **Google Gemini בשכבה החינמית** – המפתח נשמר בקובץ `.env` (שלא עולה לגיט) ונטען עם `python-dotenv`.
6. **Top K = 4** – שולפים את 4 החתיכות הדומות ביותר לשאלה. מספיק כדי לכסות תשובה, בלי להציף את המודל.
7. **gemini-embedding-001 + gemini-3.5-flash-lite** – אותו מודל embedding חייב לשמש גם לאינדקס וגם לשאלה, אחרת הווקטורים לא "מדברים באותה שפה". flash-lite מהיר וחסכוני ליצירת התשובה.
   > **הערה:** במקור תוכנן `gemini-2.5-flash-lite`, אבל Google החזירה שגיאה שהמודל כבר לא זמין למשתמשים חדשים, ולכן הוחלף לגרסה החדשה `gemini-3.5-flash-lite` (שורה אחת ב-`config.py`).
8. **הרחבת שאלה קצרה** – שאלה כמו "כוויה?" (פחות מ-5 מילים) מנוסחת מחדש ע"י ה-LLM לשאלה מלאה, וכך החיפוש מדויק יותר. שאלה ארוכה נשלחת כמו שהיא, כדי לחסוך קריאה ל-API.
9. **דמיון קוסינוס + סף 0.5** – האוסף ב-Chroma מוגדר עם `hnsw:space: cosine` (ההגדרה נמצאת ב-`config.py`, ו-`rag.py` מוודא שהאוסף אכן נבנה כך). אחרי השליפה, `SimilarityPostprocessor` זורק חתיכות עם ציון נמוך מ-0.5. אם לא נשאר אף אחת – הבוט עונה "לא מצאתי מידע על כך במסמכי העזרה הראשונה" ולא ממציא.

**בנוסף:** פרומפט בעברית מורה למודל לענות אך ורק לפי הקטעים שנמצאו, לא לנחש ולא להשתמש בידע כללי.

## תקלות נפוצות

- **"האינדקס עוד לא נבנה"** – הריצי `python build_index.py`.
- **"לא נמצא GOOGLE_API_KEY"** – ודאי שיש קובץ בשם `.env` (ולא `.env.txt`) בתיקיית הפרויקט.
- **שגיאת 429 / quota** – חרגת ממכסת השכבה החינמית. חכי דקה ונסי שוב.
